# LilyGO T-Display-S3 — Web GIF Player

Автономный плеер анимированных GIF-изображений для отладочной платы **LilyGO T-Display-S3** (ESP32-S3) со встроенным веб-интерфейсом для беспроводной загрузки файлов по Wi-Fi.

---

## ✨ Возможности

* **Воспроизведение GIF**: цикличный рендеринг анимаций на IPS-экране разрешением 320×170 с автоцентрированием.
* **Веб-интерфейс загрузки**: встроенная адаптивная веб-страница (с автопереключением темы Dark/Light) для пакетной загрузки `.gif`, удаления файлов и выбора активной анимации.
* **Быстрое подключение**: генерация динамического QR-кода на экране для мгновенного подключения смартфона к точке доступа платы и перенаправление через Captive Portal.
* **Энергосбережение**:
  * Автоматическое выключение точки доступа Wi-Fi через 4 минуты неактивности.
  * Режим глубокого сна (Deep Sleep) с полным отключением экрана и подсветки.
* **Мониторинг батареи**: расчет и отображение оставшегося уровня заряда аккумулятора в веб-панели.
* **Файловая система LittleFS**: транслитерация кириллических имен и предотвращение конфликтов при сохранении файлов.

---

## 🛠 Аппаратные особенности и управление

* **Плата**: LilyGO T-Display-S3 (ESP32-S3 Dual Core, 8MB PSRAM, 16MB Flash).
* **Дисплей**: ST7789V (170×320, 8-bit Parallel).

### Назначение кнопок:

| Кнопка | Действие | Результат |
| :--- | :--- | :--- |
| **BOOT (GPIO 0)** | Короткое нажатие | Запуск Wi-Fi сервера и показ экрана с QR-кодом |
| **Верхняя кнопка (GPIO 14)** | Удержание 1.5 сек | Переход в режим глубокого сна (Deep Sleep) |
| **Верхняя кнопка (GPIO 14)** | Нажатие во время сна | Пробуждение устройства |

## 📦 Необходимые библиотеки

Перед компиляцией установите следующие библиотеки через менеджер библиотек Arduino IDE:

1. **[TFT_eSPI](https://github.com/Bodmer/TFT_eSPI)** — вывод графики на дисплей.  
   > ⚠️ **Важно**: в настройках библиотеки `TFT_eSPI` (в файле `User_Setup_Select.h`) обязательно раскомментируйте пресет для платы:  
   > `#include <User_Setups/Setup206_LilyGo_T_Display_S3.h>`
2. **[AnimatedGIF](https://github.com/bitbank2/AnimatedGIF)** — декодер анимаций.

## ⚙️ Настройки платы в Arduino IDE

Откройте меню **Инструменты (Tools)** и выставьте следующие параметры:

* **Board**: `ESP32S3 Dev Module`
* **USB CDC On Boot**: `Enabled`
* **CPU Frequency**: `240MHz (WiFi)`
* **Core Debug Level**: `None`
* **USB DFU On Boot**: `Disabled`
* **Erase All Flash Before Sketch Upload**: `Disabled`
* **Events Run On**: `Core 1`
* **Flash Mode**: `QIO 80MHz`
* **Flash Size**: `16MB (128Mb)`
* **JTAG Adapter**: `Disabled`
* **Arduino Runs On**: `Core 1`
* **USB Firmware MSC On Boot**: `Disabled`
* **Partition Scheme**: `16M Flash (3MB APP/9.9MB FATFS)`
* **PSRAM**: `OPI PSRAM`
* **Upload Mode**: `UART0 / Hardware CDC`
* **Upload Speed**: `921600`
* **USB Mode**: `Hardware CDC and JTAG`
* **Zigbee Mode**: `Disabled`

## 🚀 Использование

1. Прошейте плату с указанными выше настройками.
2. Нажмите кнопку **BOOT (GPIO 0)**.
3. Наведите камеру телефона на появившийся **QR-код** для автоматического подключения к сети `ESP-32 GIF` (пароль: `12345678`).
4. Дождитесь открытия страницы авторизации (Captive Portal) или перейдите в браузере по адресу `http://192.168.4.1`.
5. Выберите один или несколько файлов `.gif` (оптимальный размер кадра — **320×170**) и нажмите **Загрузить**.
6. Переключайте сохраненные файлы или выключайте экран платы прямо из веб-интерфейса.
